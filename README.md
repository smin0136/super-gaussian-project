## Publish

1. Create the GitHub repository `super-gaussian-project` under `smin0136`.
2. Push this folder to the repository root.
3. In GitHub repository settings, enable Pages with source `Deploy from a branch`, branch `main`, folder `/ (root)`.
4. After the repository is public, update the disabled GitHub Repo button in `index.html` to link to `https://github.com/smin0136/super-gaussian-project`.
